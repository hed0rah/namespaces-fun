Run

Clone the repo and start with the demos. All scripts hold the namespace open for sixty seconds so you can poke at it from another terminal. Ctrl+C tears down early.

  • $git clone https://github.com/hed0rah/namespaces-fun && cd namespaces-fun
  • $chmod +x demos/*.sh nsm/nsm
  • $sudo ./demos/01-uts-hostname.shhostname isolation, gentlest intro
  • $sudo ./demos/03-net-namespace.shveth pair, the Docker way
  • $./demos/05-user-namespace.shno sudo, rootless containers basis
  • $sudo ./demos/07-mini-container.sha real container in pure bash
  • $sudo cp nsm/nsm /usr/local/bin/nsminstall the CLI
  • $nsm listall namespaces on the system
  • $sudo nsm diff 1 $$compare your shell to init
